# ComputerTemp

Cross-platform hardware temperature & system monitoring application.

## Platforms

| Platform | Folder | Tech Stack |
| :--- | :--- | :--- |
| **Windows** | [`windows/`](windows/) | C# / .NET 8 Windows Forms, LibreHardwareMonitorLib |
| **macOS** | [`macos/`](macos/) | Swift 5.9 / SwiftUI, IOKit (AppleSMC), Swift Charts |

See each folder's documentation (`windows/Temp.sln` or [`macos/README.md`](macos/README.md)) for build and run instructions.
